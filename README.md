# yonggeun-jung.github.io

Personal academic website for **Yonggeun Jung**, Ph.D. student in Economics at the University of Florida.

- **Stack:** [Jekyll](https://jekyllrb.com/) on [GitHub Pages](https://pages.github.com/)
- **Theme:** Custom layout inspired by [orderedlist/minimal](https://github.com/orderedlist/minimal) (see [/attribution/](https://yonggeun-jung.github.io/attribution/))

## Local preview

With Ruby and Bundler:

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open `http://localhost:4000`.

The repository began from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) / Minimal Mistakes stack; legacy theme files remain for compatibility but main pages use the `minimal` layout.
